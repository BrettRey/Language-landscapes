# Chapter 18 Master English Terms for Localizers
Purpose: give localizers a single English reference list for Chapter 18, "Subordination and coordination." This is not a list of required target-language translations. It identifies the English terms whose technical force should be preserved, especially at first occurrence.
## Global Rule
At first occurrence, use the chosen target-language term and give the English term in parentheses:

```tex
\term{target-language term} (\term{English term})
```

After first occurrence, use the target-language term alone unless the local term is risky or the paragraph explicitly compares terms. If the local equivalent invites a likely misconstrual, add a short warning, analogy, or diagnostic in the prose. The translated chapter may therefore contain brief explanatory material that is not in the English source.

Keep `Sdr`, `Crd`, and `Mk` as compact analytical labels unless a local edition remakes the figures and tree labels throughout.

For `\mention{...}`, leave the English object-language form in English when the form itself is being discussed. Add a local gloss only when needed for comprehension, for example the `whether` meaning of `if`, or the "at least as tall as" reading of `as tall as`.
## Core Terms
| English term | Abbrev. | Localizer note |
| --- | --- | --- |
| subordination |     | Process/relation in which one clause is made dependent within another structure. Contrast with coordination as hierarchy vs equality. |
| coordination |     | Equal-status joining. Do not let the term mean only loose discourse connection, administrative coordination, or semantic relatedness. |
| subordinate clause |     | A clause that is dependent within another structure. Relational term. |
| matrix clause |     | The clause that contains a subordinate clause. Relational term. Do not collapse into `main clause`. |
| main clause |     | A clause not contained in a larger matrix clause. Syntactic type, not a relational position. |
| dependent |     | Element that depends on another element in structure. Used when defining subordination and markers. |
| content clause |     | Default type of subordinate clause, not defined by complement function. Avoid terms that imply "complement clause" unless clearly framed as a bridge. |
| declarative content clause |     | Content clause with declarative form/meaning. Do not translate as "affirmative"; polarity is separate. |
| interrogative content clause |     | Content clause with interrogative form/meaning. Do not reduce to "question." |
| basic interrogative |     | The book's label for the yes/no-type interrogatives in this chapter. Do not silently replace with a different framework's term. |
| focused interrogative |     | The book's label for interrogatives with a focused interrogative word such as `what` or `how`. |
| comparative clause |     | Subordinate clause completing a comparison, typically with ellipsis. |
| relative clause |     | Subordinate clause type treated mainly in Chapter 19. Keep distinct from content and comparative clauses. |
| subordinator | Sdr | Lexical category containing items such as `that`, `whether`, and `if` meaning `whether`. It functions as a marker; it is not a head and does not project an SdrP. |
| coordinator | Crd | Lexical category containing `and`, `or`, and `but`. It functions as a marker in coordination; do not treat it as the head of the whole coordinate structure. |
| marker | Mk  | Syntactic function: a dependent that signals how its head relates grammatically to a larger structure. Distinguish from the categories `subordinator` and `coordinator`. |
| coordinate |     | One of the equal-status elements in a coordinate structure. Can be a clause, phrase, or sometimes a mixed category where the function is shared. |
| coordinate structure |     | The whole non-headed construction made up of coordinates, usually with or without coordinators. |
| non-headed construction |     | A construction with no single head. Important for coordination. |
| head |     | Structural center of a headed phrase/clause. Coordination is different because no coordinate is the head of the whole. |
| complement |     | A dependent licensed by a head. In Chapter 18 it is important because content clauses can appear as complements but are not defined only by that function. |
| modifier |     | A dependent that adds information without being selected in the same way as a complement. |
| adjunct |     | Modifier-like function used in labels such as `time adjuncts`. Avoid local school-grammar terms that blur complement vs adjunct if they create confusion. |
| syntactic function |     | Function in a larger structure, such as complement, modifier, subject, or coordinate. Coordination requires functional similarity. |
| lexical category |     | Word-class category such as noun, verb, subordinator, or coordinator. Distinguish from syntactic function. |
| phrase |     | Headed unit below clause level. Important where local terms for "phrase" may be false friends for "sentence." |
| clause |     | VP-headed syntactic unit, normally with a subject. Keep distinct from sentence and phrase. |
| finite subordinate clause |     | Mentioned in the overview of subordinate-clause types. |
| non-finite subordinate clause |     | Mentioned in a footnote only; no full treatment in this sample. |
## Coordination Terms
| English term | Localizer note |
| --- | --- |
| sentence-initial coordinator | A coordinator such as `and` or `but` at the beginning of a sentence. The chapter rejects the prescriptive ban but says this is not tight syntactic coordination with the previous sentence. |
| discourse connector | The function a sentence-initial coordinator can serve across sentences. Keep distinct from syntactic coordination inside a single structure. |
| symmetric coordination | Order of coordinates does not affect the relevant meaning. |
| asymmetric coordination | Order of coordinates affects meaning, often because it implies temporal or logical sequence. |
| distributive coordination | The property applies to each coordinate individually. |
| joint coordination | The property applies to the coordinates together as a group. |
| asyndetic coordination | Coordination without an overt coordinator. |
| syndetic coordination | Coordination with an overt coordinator. |
| repeated coordinators | Pattern such as `red or white or blue`. |
| correlative coordination | Coordination with paired or distributed markers, such as `both...and`, `either...or`, `neither...nor`. |
| layered coordination | Coordination inside coordination, such as `short and sweet but complex and thought-provoking`. |
| functional similarity | Coordinates must be able to serve the same function when used alone. |
| functional identity | The stronger version used in the coordination-structure section: coordinated elements must share the same syntactic function. |
| expanded coordinate | A coordinate together with its coordinator. The chapter uses fronting to show that an expanded coordinate cannot be moved to the front. |
| fronting | Moving an element to the front. Used diagnostically in the coordination section. |
## Comparison And Mandative Terms
| English term | Localizer note |
| --- | --- |
| ellipsis | Recoverable material is omitted. Distinguish from a gap, which is a syntactic position. |
| gap | A structural position in a tree. The chapter contrasts gaps with ellipsis in a footnote. |
| pro-form | Used for `did` replacing a VP in comparative examples. |
| equality | Label for `as...as` comparison. Warn if the local term suggests exact equality: `Kim is as tall as Pat` means Kim is at least as tall as Pat and may be taller. |
| inequality | Label for `than` comparison. |
| mandative | English-specific subordinate construction with predicates of requirement or necessity, as in `It is essential that he be there`. |
| mandative construction | Fuller term for `mandative` when a bare adjective/noun term is unclear in the target language. |
| subjunctive | In this chapter, the mandative plain-form variant. Do not let mood terminology imply counterfactual meaning. |
| present subjunctive | Useful in languages where plain `subjunctive` is too broad or misleading. |
| indicative | Variant using an ordinary tensed form. |
| should variant | Variant using `should be`. Leave `should` as the English form under discussion. |
| subject-auxiliary inversion | Diagnostic difference between main-clause interrogatives and subordinate interrogative content clauses. |

## English Object-Language Forms
These forms should generally remain in English inside `\mention{...}` because the English form itself is being analyzed:

| Form | Note |
| --- | --- |
| `that` | Declarative subordinator in content clauses. |
| `whether` | Basic interrogative content-clause marker. |
| `if` | Only the `whether` meaning is a subordinator here; distinguish from conditional `if`. |
| `and` | Coordinator for addition and some asymmetric conditional readings. |
| `or` | Coordinator for alternatives and some negative conditional readings. |

## High-Risk Misconstruals To Guard Against
1. `Main clause` and `matrix clause` are not synonyms. A clause can be both main and matrix, or subordinate and matrix, but not both main and subordinate.
  
2. `Content clause` is a clause type, not a function. It can appear in several functions, including subject and complement positions.
  
3. `Subordinator` and `coordinator` are categories. `Marker` is a function. Do not choose local terms that make this contrast impossible.
  
4. `Coordination` is syntactic equal-status joining, not just a discourse connection or a list of related ideas.
  
5. A sentence-initial `and` or `but` can be good English, but it is not tight syntactic coordination with the previous sentence. It can act as a discourse connector.
  
6. `As...as` equality is not necessarily exact equality. It means at least as much in the relevant dimension.
  
7. The mandative `subjunctive` in `that he be there` is about English plain verb form in a requirement context, not about unreality or counterfactuality.
  
8. `Ellipsis` and `gap` are both about something absent, but they are not the same analysis. Ellipsis is recoverable material; a gap is a syntactic position.
