# Copy Deck

## Product name

Language Landscapes AI Companion

## One-line value proposition

Ask the book questions, browse its chapters, and inspect the passages behind every answer.

## Alternate value proposition

A guided interface to *Language landscapes* that keeps the source text in view.

## Landing intro

This companion helps readers explore *Language landscapes* by asking questions in natural language, browsing the book’s structure, and tracing every answer back to the source.

## Trust statement

Answers should stay grounded in the book and cite the chapter or section they come from.

## Example prompts

- What distinction does the book make between categories and functions?
- Where does it discuss Standard English?
- Explain grammaticality in plain language.
- Compare pragmatics and conversation.
- Quiz me on negation.

## UI labels

- Ask the book
- Browse chapters
- Explore topics
- Sources
- Try a prompt
- View passage
- Show sources
- Hide sources
- Ask a follow-up

## Empty-state copy

Start with a question about the book, or browse the chapters to find a path in.

## Weak-match copy

I couldn’t find a strong answer in the indexed text. Try a narrower question, or start from one of these related chapters.

## Citation examples

- Source: Categories and functions: An overview > Categories
- Source: Pragmatics > Cooperation and implicature

## Suggested chapter groups

- Foundations
- Structure
- Sound and writing
- Meaning and use
- Discourse and interaction

## Short rationale the design can echo

The companion should feel like a map, a notebook, and a conversation with a careful teacher all at once.
