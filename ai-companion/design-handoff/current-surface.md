# Current Surface

There is already a working local prototype.

It is functionally useful but visually basic.

## What it currently has

- a single-page chat interface
- a top header with product title
- a central conversation pane
- a right-side source rail
- a large multiline ask box
- toggles for model usage and retrieval count
- retrieval-first answers with cited source cards

## Current visual character

- clean and readable
- warm light palette
- utilitarian rather than distinctive
- more like a developer tool than a finished reading companion

## What the redesign should improve

- stronger first impression
- better explanation of what the product is for
- more legible relationship between answer and source passages
- more inviting chapter browsing
- clearer empty state and prompt suggestions
- more intentional typography and visual system

## What should stay conceptually

- answer panel
- source inspection
- chapter-aware product framing
- grounded, trustworthy tone

Do not treat the redesign as a mandate to preserve the exact current layout.

Treat the current surface as the functional baseline, not the design target.
